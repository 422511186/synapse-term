## Why

用户已经在 Session 中通过 SSH、跳板机、容器、WSL 或切换用户到达目标环境，再用独立文件客户端通常无法沿用全部认证链路。应用需要在当前终端内提供文件上传、下载和环境快照，同时让目标机器收到的执行命令保持明文可审计，不要求用户再次输入密码、密钥或验证码。

## What Changes

- 新增桌面 UI 的多文件与目录上传、下载，提供按钮、拖入、远端路径输入、进度和取消；同名默认保留原文件并提示处理，不增加远端文件浏览器。
- 沿用当前 Session 的 PTY 通道和已完成的认证，以操作时实际响应的最内层环境及当前身份为目标；不重建 SSH/SFTP 连接，不解析跳转拓扑。
- 支持 Linux、macOS、Windows 目标环境。文件传输可以占用当前终端，用户保留取消、中断和接管能力；状态采集与传输、外部执行互斥。
- 新环境由用户在空闲 Shell 主动启用一次。应用提供完整可检查的明文启用过程；每次操作重新验证本次响应，旧能力代际、执行上下文或环境名称不作为目标身份证明。
- 提供文件工具的手动检测、明确启用流程内的一次自动检测和有效传输准备流程内的按需复检；候选 `trzsz` 分别检测上传接收工具 `trz` 与下载发送工具 `tsz` 的路径、版本及运行能力。打开面板不触发检测，超时不等于工具缺失，过期结果不授权操作。
- 通过分平台的固定明文命令获取环境、当前用户、目录、CPU、内存和磁盘的按需快照。启用时采集一次，随后手动刷新；明确显示采样时间、统计口径、暂停、过期和不可用项。
- 所有部署、启动、采集和文件操作命令均以可读原文发送。禁止加密命令、Base64 命令或脚本、解码执行及通过辅助程序的编码消息隐藏实际执行；允许文件内容作为纯文件协议数据编码传输。
- 目标已有兼容工具时直接明文启动；缺失、不兼容或执行受限时分别提示原因，并提供适用的快速安装、复制完整安装命令和重新检测入口。快速安装先展示目标环境、来源、固定版本、安装位置及联网/权限条件，由用户选择在当前终端执行；复制命令本身不执行。
- 应用经当前终端离线、普通用户权限提供组件仍是基线要求。经验证且目标认可的联网包管理器安装仅作为用户明确选择的可选路径，不能替代离线部署验收。安装完成后复核路径、版本和可运行性，再返回原上传/下载准备步骤；不自动传文件、提权、重试未确认安装或索取凭证。三平台部署与目标审计仍须先取得真实证据。
- 文件载荷、传输协议及内部结构化快照在 Main 分流，不进入普通终端文本或 Sharing 历史；普通明文命令及可读结果继续遵循既有终端与 Sharing 边界。
- 保持 Session 和运行状态仅存在于当前应用运行期。用户选定保存的文件属于本次传输结果，不构成 Session 持久化；不增加主机资产、凭据库、审计收集服务或 MCP 文件工具。

## Capabilities

### New Capabilities

- `terminal-operation-audit`：本地终端操作的明文命令、首次启用、受控检测、组件安装与复检边界，以及目标侧审计与兼容性证据要求。
- `terminal-file-transfer`：沿当前 PTY 通道进行多文件和目录上传下载，涵盖目标绑定、路径与覆盖规则、流式传输、取消及结果确认。
- `terminal-environment-snapshot`：Linux、macOS、Windows 最内层当前环境的按需状态快照，涵盖明文采集、指标口径、失效和不可用状态。

### Modified Capabilities

- `terminal-sessions`：增加本地操作与外部写入的 Session 级协调、实例失效和输出分流，保留本地用户控制权及现有生命周期。
- `desktop-terminal`：在 Session 内容区提供文件操作、工具检测与快速安装引导、环境快照入口、状态与受限 IPC；Header 继续不展示资源监控。
- `mcp-session-sharing`：明确文件协议和内部快照不得进入 Sharing 输出；普通可读文本及现有外部工具契约继续生效。

## Impact

- `packages/domain`：新增本地操作、文件结果与环境快照的纯数据契约；不改变 Session 的传输无关定义。
- `packages/terminal-service`：扩展 SessionActor 的有序操作协调、协议解析与分流、目标实例绑定和中断清理。
- `packages/session-runtime`：承载本地文件操作、平台采集、生命周期和受限进度/快照接口；只通过下层包公共出口访问能力。
- `apps/desktop`：Main 持有本机文件选择、文件 I/O 能力和组件资源，preload 暴露有限操作接口，Renderer 提供 Session 内的操作 UI。
- `packages/mcp-runtime`：复用 Session 级写入协调并接收已隔离的普通输出；不增加工具、文件访问授权或机器状态字段，不改变三档审批模式。
- 依赖候选为 `trzsz` 及平台组件，最终版本、协议适配和是否采用须由前置验证确定，不能把上游支持声明当作本项目已经通过验收。
- 在同一变更的实施阶段更新 `CONTEXT.md`、记录通过验证后的架构取舍，并同步架构、安全、测试与操作说明。当前提案仅形成规划，不宣称三平台部署或目标审计已经通过。
