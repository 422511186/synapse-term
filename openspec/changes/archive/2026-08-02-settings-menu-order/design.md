## Context

桌面全局设置菜单（`apps/desktop/src/renderer/app.tsx`）当前顺序为：模型配置 → 服务商配置 → MCP 服务 → ACP。模型配置必须引用服务商（Provider），先配置服务商再配置模型更符合操作顺序。

## Goals / Non-Goals

**Goals:**
- 全局设置菜单中“服务商配置”位于“模型配置”上方。
- 调整仅限菜单项顺序，不改变配置语义与持久化格式。

**Non-Goals:**
- 不改设置页内部布局、模型切换菜单或其他入口。

## Decisions

**D1：直接互换设置菜单中两个按钮的 JSX 顺序。**

在设置菜单区块中把“服务商配置”按钮移到“模型配置”按钮之前，图标（Key / Box）与点击行为不变。改动局限在单个菜单区块，无状态与路由变化。

备选：按配置依赖关系抽象菜单排序配置 —— 不采用，两个入口的排序是静态需求，引入配置层属于过度设计。

## Risks / Trade-offs

- [用户习惯旧顺序短期不适应] → 菜单项文案与图标不变，仅顺序调整，风险极低。

## Migration Plan

无需迁移；发布后新顺序即生效。
