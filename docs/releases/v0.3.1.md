# Synapse Term v0.3.1

Synapse Term v0.3.1 是一次面向跨平台终端环境、Agent 运行状态、MCP 外部接入和桌面交互反馈的稳定性更新。本版本集中处理了终端启动环境不完整、Agent 时间线重复或卡在进行中、外部终端调用难以恢复，以及桌面异步操作反馈不一致等问题。

## 主要变化

### 跨平台 Shell 环境

- macOS 的 Zsh 和 Bash 会以登录交互模式启动，使 `.zprofile`、`.zshrc`、`.bash_profile` 和 `.bashrc` 等用户环境配置有机会生效。
- Windows 会自动发现 Git Bash、PowerShell 和 WSL，并在可用时使用正确的可执行文件、启动参数和命令方言。
- Git Bash 以 `--login -i` 启动，PowerShell 保持 PowerShell 方言，WSL 标记为 POSIX 方言；应用不会把 WSL 内的命令误判为 Windows PowerShell 命令。
- Shell 探测会在环境尚未确认时使用受控探测流程，并在超时、终端退出、占用或环境不明确时退回只观察状态，避免把不确定的 Shell 当作已验证环境执行命令。

### Agent 时间线与运行状态

- 对流式事件、工具调用、命令和工具结果使用稳定 ID 合并，避免同一个模型事件同时显示为多张重复卡片。
- 页面重新加载或从历史恢复后，会重新建立时间线和工具卡片状态，不再把已结束任务长期显示为“进行中”。
- 终态优先级得到统一处理，完成、失败、取消、Shell 丢失和协议错误等状态会覆盖旧的运行状态。
- Agent 面板增加运行状态、耗时和无活动时的思考占位反馈，便于区分正在处理、等待用户和已经结束的任务。

### MCP 终端会话

- 内嵌 MCP 增加 `terminal_status`，外部客户端可以先检查会话是否就绪、未就绪或已失效，再决定是否执行命令。
- MCP 错误转换为稳定、可解析的错误码，例如 `SESSION_NOT_READY`、`SESSION_EXPIRED`、`SESSION_BUSY`、`TERMINAL_BUSY`、`POLICY_DENIED` 和 `SHELL_LOST`，并附带恢复指引。
- 增加完整权限模式的端到端处理，同时继续由 Core 的会话租约、命令策略和审计管线负责实际边界控制。
- 共享会话支持端口持久化和自动探测；外部客户端在会话不可用时会得到明确结果，而不是无限等待或收到内部异常细节。
- MCP 工具和设置页补充测试，覆盖端点配置、token、共享会话、事务等待、中断和错误映射。

### 桌面端交互反馈

- 统一成功、失败和信息提示的 toast 行为，并合并相同提示，减少重复消息。
- 异步操作统一使用待命、进行中和成功三态；进行中的按钮会禁用，避免重复提交和重复请求。
- 设置页、Provider/Model 操作、ACP 和 MCP 操作补充错误反馈及成功确认，用户可以看到操作是否仍在进行。
- Agent 运行状态栏和交互反馈加入桌面端 E2E 覆盖，验证状态变化、错误提示和防连点行为。

### 规格、文档与发布工程

- 归档本轮已完成的 OpenSpec 变更，并将跨平台 Shell、MCP、Agent 执行、桌面模型管理、终端会话和交互反馈的 delta spec 同步到主规格。
- 保持 GitHub Actions 的发布链路：Ubuntu 验证、Windows x64 构建、macOS arm64 构建、Core/维护入口 smoke、SHA256 校验和自动创建 Release。
- 当前版本号同步到根目录 `package.json`、发布报告、真实 Agent 验证入口和 Windows 安装器生命周期验证脚本。

## 安装与首次启动

- Windows 发布资产为 x64 NSIS 安装包。
- macOS 发布资产为 arm64 DMG，适用于 Apple Silicon Mac。
- 当前 Release 未配置 Windows 或 macOS 产品签名证书。macOS 首次打开若提示应用来自身份不明的开发者，可先将应用拖入 `/Applications`，再在终端执行：

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Synapse Term.app"
  ```

  然后从“应用程序”目录启动应用。该命令只移除下载文件的隔离属性，不会为应用添加开发者签名。
- `codex`、`opencode` 等外部 CLI 不随 Synapse Term 安装包发布。ACP 使用的外部运行时需要用户单独安装，并确保桌面进程启动时能够从 PATH 找到它；MCP 则通过应用内嵌端点接入。

## 验证与下载

发布工作流会在创建 Release 前重新执行 `pnpm verify`，并在 Windows 和 macOS runner 上构建安装包及运行 Core、维护入口 smoke。Release 同时提供 `SHA256SUMS.txt`，下载后可用本机 SHA-256 工具核对安装包完整性。

## 已知限制

- 未签名安装包可能触发 Windows SmartScreen 或 macOS Gatekeeper 提示。
- 当前 GitHub Release 提供 Windows x64 和 macOS arm64 构建，不包含 Windows arm64、macOS Intel 或 Linux 安装包。
- 真实 Provider、模型凭据、SSH 和远程环境验收依赖用户自己的环境，不属于默认发布门槛。
- 安装文件名和部分兼容路径仍保留 `Terminal-Agent` / `terminal-agent` 标识；产品名称、workspace 包名和 Release 名称为 `Synapse Term`。
