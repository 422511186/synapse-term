# ADR-0016：完成探针回显只影响本地终端 UI

状态：已接受

## 决策

“隐藏完成探针回显”作为通用设置，只改变本地终端 UI consumer 是否显示完成探针的输入回显。PTY 仍然接收固定明文 Probe，目标 Shell、SSH、终端和远程服务器仍可按自身配置记录这些输入。

SessionActor 将 PTY 输出拆成两条受控路径：协议路径始终隔离 OSC 777 和完成探针噪声，供事务完成检测和 MCP 输出缓冲使用；终端 UI 路径根据通用设置显示或隐藏输入回显。两条路径都不向 Renderer 暴露 Node、PTY 或 Session 内部状态。

## 理由

本地诊断可见性与远程审计可见性是两个不同边界。把开关接到 PTY 写入或 MCP 输出会造成不可审计的命令行为或协议噪声泄露；把它限定在 UI consumer 可以同时满足诊断需求和现有明文审计、输出脱敏边界。

## 影响

关闭隐藏只适用于排查 ConPTY 重绘、Shell 回显等本地问题。它不会减少目标机器收到的字节，也不会改变命令退出码、事务完成检测、外部调用审批或输出脱敏。
