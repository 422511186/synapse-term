# ADR-0023：MCP 审批由设置驱动且默认拒绝高风险操作

状态：已实现

## 决策

MCP 使用独立设置：`read_only` 自动允许观察、等待和读取，拒绝写类能力；`managed` 允许低危调用，但高危、未知、特权和破坏性调用仍被拒绝。高危操作不能配置成永久放行。

## 当前实现

`mcp-settings.ts` 默认关闭并使用 `read_only`；`mcp-tools.ts` 只注册四个终端工具和三个只读文件工具，`ExternalToolPipeline` 负责策略、脱敏和审计。

## 影响

MCP 调用不依赖用户是否正打开某一张审批卡片。若未来需要人工审批，应复用平台审批通道，而不是在 MCP 客户端内新增第二套权限记忆。
