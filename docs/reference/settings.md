# 设置参考

## 通用设置

通用设置控制应用级行为，例如应用更新自动检查和完成探针回显可见性。隐藏完成探针回显只影响本地终端 UI，不影响 Probe 是否写入 PTY，也不承诺远程 Shell 或服务器不会记录它。

## 主题和终端

主题设置控制界面模式和终端配色。终端尺寸、字体和显示选项只影响 Renderer 的呈现，不改变 Session 的 PTY 语义。

## MCP 服务

| 设置 | 作用 | 默认/边界 |
| --- | --- | --- |
| 启用 | 启动或停止本机内嵌 MCP Server | 默认关闭 |
| 端口 | 回环 MCP 端点监听端口 | 默认 `4739`，范围 `1` 到 `65535` |
| 审批模式 | 选择 `read_only`、`managed` 或 `full` | 配置缺失或损坏时回退 `read_only` |
| Token | Bearer 鉴权凭据 | 启用时生成；可轮换或吊销 |

启用、轮换或吊销 Token 会清理已有 Sharing、审批和外部事务。Token 由本机设置存储管理，不应复制到 Share Text 或命令文本中。

## 来源

设置是应用运行和本机配置的事实，不代表远程主机状态。MCP 工具能看到的字段以 [MCP 工具参考](mcp-tools.md) 为准。
