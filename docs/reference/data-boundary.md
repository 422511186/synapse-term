# 本地数据边界

Synapse Term 以当前操作系统用户为本地边界，不提供产品账户、共享工作区或集中审计服务。

## 只在运行期存在

- Session、PTY 和实时终端输出。
- 当前 Sharing 输出历史、游标和外部事务句柄。
- 审批队列、会话内放行记忆和输入去重记录。

应用退出或 Session/Sharing 结束后，这些运行期对象会释放；它们不跨应用重启恢复。

## 可以本地保存

- 通用设置、主题和终端偏好。
- MCP 端口、审批模式和本机访问 Token。
- 更新偏好、更新公钥和有限的安装包缓存。

更新缓存不包含 Session、终端输出、运行凭据或可重放的安装授权。旧 `terminal-agent` 数据目录不再作为当前数据来源。

不要把整个 Electron `userData` 目录当作可随意删除的缓存。清理前先确认通用设置、本机 MCP 配置和 Token、更新偏好及缓存会受到什么影响。

## 不提供

- 产品账户或远程同步。
- 远程主机资产、SSH 拓扑和远程凭据库。
- 集中审计日志、跨重启终端回放或全量屏幕快照。

MCP 输出只覆盖当前 Sharing 边界内的有限保留窗口，并经过协议帧清理和脱敏。详细安全假设见[安全边界](../security/security.md)。
