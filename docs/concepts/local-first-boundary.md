# 本地优先边界

Synapse Term 的产品边界是“单用户、本机运行”。操作系统用户是使用和配置的本地边界，应用不建立产品账户、共享工作区或集中策略服务。

## 应用负责什么

- 在本机发现 Shell 并创建 PTY；
- 管理 Session 生命周期、终端输入输出和 UI 订阅；
- 在用户明确 Sharing 后，为本机外部客户端提供受控 MCP 能力；
- 在本机保存必要的设置、MCP Token 和更新缓存。

## 应用不负责什么

- 远程主机资产、SSH 拓扑或远程凭据；
- 远程进程是否仍在运行、是否具有某项权限或是否可以回滚；
- 跨应用重启恢复 Session、终端输出或外部事务；
- 产品级账户、远程同步和集中审计日志。
- 模型运行、Provider、ACP 或外部客户端自身的配置与凭据管理。

当用户进入 SSH、跳板机、容器或 WSL 时，远程环境仍通过同一个本地 PTY 驱动。应用只依据当前 PTY 的可验证输出和运行状态，不把远程连接提升为新的领域对象。

## 对用户的影响

- 关闭窗口不等于获得后台云端 Session；应用退出时 Session 会结束。
- Sharing 需要每次由用户显式选择，不会自动发现或发布其他 Session。
- 更新安装可能结束当前 Session，更新后不会恢复；安装前会显示影响并要求一次性确认。
